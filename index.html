Briefing 02

The Scrolls of the Present

Three techniques get a quick refresh. Two are brand new, and they're the ones that will decide the final trial.
RECAP: PRESENT SIMPLE vs PRESENT CONTINUOUS

Present simple: rules and routines that are always true. Present continuous: happening right now.

  • A warrior respects his sensei. (always true)
  • Look, he's drawing his sword right now. (happening now)
alwaysevery dayright now
RECAP: GOING TO

Going to: a decided plan, or a prediction based on something you can see right now.

  • I'm going to train with a new sensei next week. (plan)
  • Look at his stance, he's going to lose his balance. (evidence)
already decidedevidence
NEW: PRESENT PERFECT SIMPLE

For experience, achievements, or a count, something happened at some point before now, and the exact moment doesn't matter.

  • I have trained in three different dojos.
  • Have you ever faced a real blade?
  • He has won five tournaments.
everneveralreadyjustso far
NEW: PRESENT PERFECT CONTINUOUS

For something that started in the past and is still going right now, the focus is on the duration, not the result.

  • I have been training since sunrise.
  • She has been practicing this technique for two hours.
has been training (reaches now)has trained (a finished event)
Compare: "I have read that scroll." (finished, a result) vs. "I have been reading that scroll." (still going, or just finished, the process is what matters)
sinceforall daylately

Mission 03

The Sacred Scrolls

The scrolls hold two laws: what is always true, and what will happen if you choose a path.
TYPE 0 vs TYPE 1

Type 0: if + present simple, present simple, an always-true law. Type 1: if + present simple, will + infinitive, a real possible future.

  • If a warrior shows no fear, opponents respect him. (Type 0)
  • If you train hard this month, you will pass the trial. (Type 1)

Which type is this?

  1. "Water boils at 100 degrees."
    Check
    Type 0, a fact that's always true
  2. "If you win this duel, you will move to the next round."
    Check
    Type 1, a real future possibility
  3. "A good student always listens to feedback."
    Check
    Type 0, a general truth
  4. "If it rains tomorrow, we will train indoors."
    Check
    Type 1, a real possible future

Now fill in the gaps

  1. If a blade ___ (touch) water, it ___ (rust).
    Check
    touches / rusts (Type 0)
  2. If you ___ (train) hard this month, you ___ (pass) the trial.
    Check
    train / will pass (Type 1)
  3. If the sensei ___ (ring) the bell, the lesson ___ (end).
    Check
    rings / ends (Type 0)
  4. If you ___ (lose) this duel, you ___ (not / advance) to the final round.
    Check
    lose / will not advance (Type 1)
  5. If a warrior ___ (show) no fear, opponents ___ (respect) him.
    Check
    shows / respect (Type 0)

Now you try

Write one Type 0 conditional (a dojo law) and one Type 1 conditional (a real prediction about your next match).
